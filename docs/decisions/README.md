# Decisions

Choices about how Clinkr works and how it's built, with the reason behind each one, one file per decision. The file names start with the date, so this folder lists them oldest first. The aim is to remember *why* something is the way it is before changing it.

Add a file in the same pull request that makes the decision, named `YYYY-MM-DD-short-title.md`, with the same date and title as its heading (`# 2026-11-06 · Short title`). Keep it to a few lines: **Decision**, **Why**, and **Instead of**, **Open** or **Also** when they help, then the **PR**. To change a past decision, add a new file and mark the old one **Replaced by** the new one, with a link, instead of rewriting it.

What changed in each release is in the [GitHub releases](https://github.com/pablocolaiacovo/clinkr/releases), so there's no separate changelog.
